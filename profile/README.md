### What Zati is

Zati is a workspace where you organize AI workers into a team, set each one's responsibilities, limits and budget, and keep the decisions that matter.

### Where the product stands

Zati is in active development, built in the open by [Sire Run, Inc.](https://sire.run)

- **In the code today:** durable workers, task delegation, acceptance checks, and authority and budget limits. Since November 11, 2026, a worker can delegate a task to another worker on the main branch.
- **In a controlled test:** a parent task and one delegated specialist both completed and were independently verified, with budgets returned.
- **Being built:** chief workers that summarize outcomes and escalate only the decisions that need the owner.
